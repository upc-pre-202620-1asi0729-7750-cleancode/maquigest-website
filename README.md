# MaquiGest — Website

Repositorio de la landing page de MaquiGest, una plataforma SaaS
para pequeñas y medianas empresas de alquiler de maquinaria
y equipos de construcción.

Desarrollada por **CleanCode** para el curso Desarrollo de
Aplicaciones Open Source de la Universidad Peruana de Ciencias Aplicadas.

## Tecnologías

- HTML5
- CSS3
- JavaScript
